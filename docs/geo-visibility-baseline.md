# PATERNOGA SEO/GEO visibility baseline

The baseline separates discoverability, retrieval, traffic and commercial outcomes. A mention is not automatically a citation; a referral is not automatically a qualified lead.

## Record before launch

For each observation store:

- date, market and language
- platform and product mode
- signed-in or neutral session context
- exact query or prompt
- whether PATERNOGA is mentioned
- whether a PATERNOGA URL is cited or linked
- cited URL and surrounding context
- other named providers or sources
- whether the result is reproducible in a second neutral observation
- screenshot or exported source where permitted

Do not average platforms into a fabricated universal “AI visibility score”. Preserve the underlying observations.

## Measurement cadence

- Weekly after launch: Search Console/Bing indexing, crawl errors, branded and non-branded impressions, and unexpected landing queries.
- Monthly: repeat the fixed prompt panel, compare source/citation changes and review the query graph.
- Quarterly: reassess commercial coverage, update genuinely changed technical guidance and repeat selected public research only with the same disclosed method.

## Decision rules

- Improve an existing page when a query is semantically covered but performs weakly.
- Consider a new page only for a distinct intent, buyer job, dataset, method or market context.
- Treat ranking, click and citation changes as observations until enough first-party evidence supports an explanation.
- Connect qualified inquiries to their landing page and stated problem without storing unnecessary personal data.
